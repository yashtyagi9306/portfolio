# Yash Tyagi — Personal UI/UX Portfolio

Personal UI/UX portfolio of **Yash Tyagi** showcasing selected products, UX case studies, interface designs, and interactive digital experiences.

🌐 **Live Website:** https://portfolio-cashews.vercel.app/ 
📦 **Repository:** [github.com/yashtyagi9306/portfolio](https://github.com/yashtyagi9306/portfolio)

---

## 🎨 Featured Projects & Case Studies

- **Medito Re-Designed** — Independent UI/UX redesign focusing on accessible meditation, reduced friction, and calming visual language.
- **Bloom EMS** — Enterprise SaaS Employee Management System with role-based dashboards and complete task lifecycle tracking.
- **Pomodoro Timer** — Distraction-free 25/5 work-break timer with task priorities and productivity streak tracking.
- **Duel** — AI-powered debate web application featuring turn-based stream interface and real-time AI Judge verdict scoring.
- **Laptop Showcase (Aero X1)** — Sleek product presentation landing page highlighting unibody design, thermals, and tier configurator.

---

## 🛠 Tech Stack

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS, Custom Design Tokens
- **Routing:** React Router v6
- **Animations:** CSS Keyframes & Framer Motion / Custom Scroll Reveals
- **SEO & Meta:** React Helmet & Structured Data (JSON-LD)

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/yashtyagi9306/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server (with HMR)
npm run dev

# Production build (outputs to /build)
npm run build

# Preview production build
npm run preview
```
